# 🛠️ Troubleshooting Guide

This document lists common errors encountered while setting up or running the Automated Ticket Checking System, along with their solutions.

---

### ❌ `ModuleNotFoundError: No module named 'qrcode'` (or `cv2`, `PIL`, `tabulate`)

**Cause:** Required library is not installed, or you're running the script outside your virtual environment.

**Solution:**
```bash
pip install -r requirements.txt
```
Or install the specific missing library:
```bash
pip install qrcode opencv-python Pillow tabulate
```
> 💡 Tip: The import name and the pip package name aren't always identical — OpenCV is imported as `cv2` but installed as `opencv-python`.

---

### ❌ Camera Not Opening / Black Window in `scan_qr.py`

**Cause:** Camera is being used by another application, wrong camera index, or driver issue.

**Solution:**
- Close other applications (Zoom, Teams, Skype) that might be using the webcam.
- Try changing the camera index in the code:
  ```python
  cap = cv2.VideoCapture(1)  # try 1, 2, etc. instead of 0
  ```
- Check that your OS has granted camera permissions to your terminal/IDE.

---

### ❌ QR Code Not Detected by Scanner

**Cause:** Poor lighting, blurry camera, QR code too small/large in frame, or reflective glare.

**Solution:**
- Ensure good, even lighting on the QR code.
- Hold the QR code steady and fill a reasonable portion of the frame.
- Avoid glossy screens/glare — a printed QR code often scans better than a phone screen.
- Clean the camera lens if the image appears blurry.

---

### ❌ Permission Issues (File Write Errors)

**Cause:** The script does not have permission to write to the Desktop path, or the path doesn't exist (common on some Linux/macOS setups).

**Solution:**
- Run the terminal/IDE with appropriate permissions.
- Manually verify the Desktop folder exists:
  ```python
  import os
  print(os.path.join(os.path.expanduser("~"), "Desktop"))
  ```
- If your OS doesn't use a "Desktop" folder by that name, edit `desktop_path` in `generate_qr.py`/`scan_qr.py` to point to a valid writable directory.

---

### ❌ `FileNotFoundError` / "QR-CODE DATA.txt not found"

**Cause:** `scan_qr.py` was run before any tickets were generated with `generate_qr.py`.

**Solution:**
- Run `python generate_qr.py` at least once to create the log file before attempting to scan/verify.

---

### ❌ OpenCV Errors (`cv2.error: ...`)

**Cause:** Usually caused by passing an invalid/empty frame to a function, often when the camera fails to initialize.

**Solution:**
- Confirm the camera is properly connected and recognized by your OS.
- Add a check for `ret` (as already done in `scan_qr.py`) to skip processing on failed frame reads.
- Update OpenCV to the latest version:
  ```bash
  pip install --upgrade opencv-python
  ```

---

### ❌ Python Path Issues ("python" or "pip" not recognized)

**Cause:** Python was not added to the system PATH during installation.

**Solution:**
- Reinstall Python and check **"Add Python to PATH"** during setup.
- Alternatively, use the full path to the Python executable, or use `py` instead of `python` on Windows.
- Verify with:
  ```bash
  where python      # Windows
  which python3     # macOS/Linux
  ```

---

### ❌ Unique ID Not Extracted (`IndexError` in `scan_qr.py`)

**Cause:** The scanned QR code does not follow the expected data format (i.e., it wasn't generated by `generate_qr.py`).

**Solution:**
- Only scan QR codes generated by this system.
- If testing with custom QR data, ensure it includes the exact substring `"Unique ID: "` followed by the ID value.

---

If your issue isn't listed here, consider opening a GitHub Issue with the full error traceback and steps to reproduce.
